# Источники данных каталога

## USDA FoodData Central

Базовый каталог сформирован из официального набора [USDA FoodData Central Foundation Foods](https://fdc.nal.usda.gov/download-datasets/), выпуск April 2026. Исходные записи идентифицируются полем `source = USDA_FDC` и оригинальным `fdcId` в `source_ref`.

В каталог включены 25 распространенных продуктов. Русские названия являются переводом описания USDA и явно сохраняют состояние продукта: сырой, сухой, консервированный или тушеный. Все значения указаны на 100 г. Для энергии используется Atwater-specific Energy, nutrient 2048, если показатель присутствует; иначе используется Energy, nutrient 1008. Белки, жиры и углеводы соответствуют nutrient 1003, 1004 и 1005.

Справочник хранится в [app/data/base_foods.py](../app/data/base_foods.py) и загружается командой:

```powershell
python -m app.commands.seed_foods
```

Команда выполняет upsert по паре `source/source_ref`: повторный запуск обновляет значения и не создает дубли. Эти данные являются справочными усредненными значениями. Для продукта конкретного бренда пользователь должен создать личную карточку по информации с упаковки.
