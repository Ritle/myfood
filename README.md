# MyFood Telegram-бот

Асинхронный Telegram-бот для дневника питания, калорий, КБЖУ и воды. Реализованы регистрация через `/start`, профиль с пошаговой анкетой, расчет рекомендуемой нормы калорий, каталог продуктов и дневник приемов пищи.

## Требования

- Python 3.12+
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather)

## Локальный запуск

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
```

Укажите токен бота в `.env`, затем примените миграции и запустите polling:

```powershell
alembic upgrade head
python -m app.commands.seed_foods
python -m app.main
```

Команда `seed_foods` загружает 25 базовых продуктов из USDA FoodData Central. Ее можно запускать повторно: существующие позиции обновятся без дублей. Состояние приготовления указано в названии, значения приведены на 100 г. Подробности и идентификаторы источника описаны в [документации данных](docs/DATA-SOURCES.md).

В разделе «Питание» выберите прием пищи, найдите продукт и укажите граммовку. Бот сохранит рассчитанный снимок КБЖУ. Кнопка «Дневник за сегодня» показывает записи по приемам пищи и позволяет изменить граммовку или удалить ошибочную запись.

Проверки:

```powershell
pytest
ruff check .
```

Параметры окружения описаны в `.env.example`. SQLite-файл по умолчанию создается как `myfood.db` в рабочем каталоге. Не коммитьте `.env` или токен бота.
