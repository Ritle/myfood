# MyFood Telegram-бот

Асинхронный Telegram-бот для дневника питания, калорий, КБЖУ и воды. Реализованы регистрация через `/start`, профиль с пошаговой анкетой, автоматический расчет дневной нормы калорий и КБЖУ с возможностью принять или скорректировать предложенные значения, каталог продуктов, дневник приемов пищи и экран дневного прогресса.

## Требования

- Python 3.12+
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather)

## Локальный запуск

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
```

Укажите токен бота в `.env`, затем примените миграции и запустите polling:

```powershell
alembic upgrade head
python -m app.commands.seed_foods
python -m app.commands.import_health_diet  # один раз
python -m app.main
```

Команда `seed_foods` загружает 159 встроенных позиций USDA FoodData Central при каждом запуске. `import_health_diet` выполняется один раз для загрузки 12 975 позиций из `health_diet_data` в БД. После импорта бот использует уже сохранённые записи и не читает эту папку. Значения приведены на 100 г; записи, которые в исходных данных явно относятся к целой порции, не загружаются. Подробности и идентификаторы источников описаны в [документации данных](docs/DATA-SOURCES.md).

В «Каталоге продуктов» есть раздел «🍽 Блюда» с 2 217 готовыми блюдами. Они также участвуют в обычном поиске из каталога и при добавлении еды в дневник.

Кнопка «➕ Создать блюдо» создаёт личную карточку блюда по тому же пошаговому вводу КБЖУ на 100 г. Она доступна только создателю, включая раздел «🍽 Блюда», поиск и дневник.

При открытии раздела «Питание» бот предлагает приём пищи по местному времени; его можно сразу переключить кнопками. Найдите продукт и выберите быструю порцию (стакан, ложка, штука и другие варианты) или введите точный вес в граммах. Несколько продуктов можно указать одной строкой, например `обед: гречка 150г, курица 180г, огурец`: бот покажет распознанные позиции и суммарные КБЖУ, а добавит их после подтверждения. Для продукта без веса подставляется 100 г с явной пометкой. Бытовые меры приблизительны, потому что их вес зависит от продукта. Кнопка «Дневник за сегодня» показывает записи по приемам пищи и позволяет изменить граммовку или удалить ошибочную запись.

Привычный прием пищи можно сохранить в шаблон из «Истории»: нажмите «Шаблон» рядом с завтраком, обедом, ужином или перекусом и задайте название. В разделе «Питание» → «Мои шаблоны» выберите его, проверьте порции и текущие КБЖУ и подтвердите добавление. На аккаунт можно сохранить до 30 шаблонов, в каждом — до 8 продуктов; ненужные шаблоны можно удалить.

Экран «Сегодня» показывает калории, КБЖУ, остаток или превышение цели и разбивку по приемам пищи. После изменения дневника бот один раз предупреждает о пересечении 80%, достижении 100% или превышении нормы. Порог предварительного предупреждения задается параметром `CALORIE_WARNING_RATIO`.

Раздел «Вода» позволяет добавлять 200, 300 или 500 мл одним нажатием либо вводить произвольный объем. Дневная история воды показывает отдельные записи, которые можно исправить или удалить. Сумма воды и заданная в профиле цель также отображаются на экране «Сегодня».

Раздел «Вес» хранит историю измерений, показывает изменение от первой записи и прогресс к целевому весу. Последнее измерение автоматически обновляет текущий вес в профиле; после исправления или удаления история и текущий показатель синхронизируются.

В «Настройках» можно включить напоминания о приемах пищи, воде и разминке, задать расписание и тихие часы, а также включить утренний отчет за предыдущий день. Для разминки выбирается интервал от 30 до 240 минут; по умолчанию эти уведомления выключены. Планировщик проверяет события с периодом `NOTIFICATION_POLL_SECONDS`. Уведомления сохраняются до отправки и не дублируются после перезапуска. Напоминание о еде можно отложить на 30 минут или пропустить до следующего дня.

Раздел «История» показывает питание, КБЖУ и воду по пользовательским дням. Новый день не начинается автоматически в полночь: пользователь завершает текущий день кнопкой «🌙 Завершить день» перед сном. Поэтому записи после 00:00 продолжают относиться к текущему дню до ручного завершения; после подтверждения начинается следующий логический день. Кнопками можно перейти на соседний день, повторить отдельный продукт или весь прием пищи, а также сохранить прием в шаблоны. Поиск в каталоге и при добавлении еды разбит на страницы; в «Недавних» можно повторно добавить продукт с последней порцией одним нажатием или выбрать его, чтобы изменить вес. Нужные карточки также можно добавить в избранное.

Проверки:

```powershell
pytest
ruff check .
```

Параметры окружения описаны в `.env.example`. SQLite-файл по умолчанию создается как `myfood.db` в рабочем каталоге. Не коммитьте `.env` или токен бота.

## Docker

После заполнения `BOT_TOKEN` в `.env` приложение можно поднять одной командой:

```powershell
docker compose up -d --build
```

При старте автоматически применяются миграции и загружается базовый каталог. База хранится в постоянном Docker-томе. Команда `/help` показывает доступные сценарии, а те же команды публикуются в меню Telegram.
